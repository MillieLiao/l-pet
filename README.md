# L 的小小日常

L 的中文静态动作试玩与换装小游戏。

- `index.html`：九组原版动作，支持暂停和逐帧查看。
- `dressup.html`：日常毛衣、小管家、小厨师、小猫咪、兔兔套装、麻将小高手、小王子、小猪套装、小杀手，共 9 套；支持随机试穿与背景换色。
- 手机、桌面浏览器和键盘均可操作。

网页不会修改 Codex 桌宠，不需要 API 密钥，也不收集或存储个人数据。服装是整套静态插画，不是可拆分混搭的衣服图层或换装动作动画。

## 文件

页面、脚本、样式和图片均放在仓库根目录，使用相对路径，可直接通过 GitHub Pages 发布。请保留 `.nojekyll`。

角色设定与服装参考由网站所有者提供。八套服装由内置 ImageGen 衍生绘制。小杀手为无武器、无血腥的卡通潜行服装。此仓库没有附加开源许可证。
